# YF-1 仿星器交互模拟平台

应聘岩超聚能（YAN Fusion）AI 产品经理岗位的作品：以公司在建的一代仿星器装置 **YF-1** 为对象的交互模拟平台原型，附完整产品方案。

## 文件

- **`index.html`** — 模拟平台本体，单文件网页，浏览器直接打开即可运行（无需构建、无后端）。
- **`岩超聚能仿星器交互模拟平台产品方案.docx`** — 产品方案（12 页）：事实基线、产品矩阵、YF-1 旗舰设计、分层体验、AI 全流程、游戏化体系、GEO/SEO 规划、版本路线图、指标与红线；附录含原型修正清单与面试讲述提纲。

## 平台能做什么

- **可亲手操作的虚拟装置**：三维仿星器可旋转查看；磁场、加热功率、燃料密度、QI 位形优化度四个参数驱动一个简化功率平衡模型（ISS04 约束标度、D–T 反应率、β 极限与密度极限），参数推过头等离子体会破裂熄灭。
- **游戏化挑战**（对应 JD 的游戏化成长体系）：三关——点亮等离子体 → 稳态运行 → Q ≥ 1，配勋章与可下载的结业证书。
- **分层讲解**（对应 JD 的分层体验设计）：大众 / 科研 / 投资人三种视角，同一台装置三套讲法。
- **AI 赋能**（对应 JD 的 AI 赋能产品全流程）：AI 运行助手实时诊断工况，并可一键优化参数。

## 事实口径说明

- 公司、产品与融资信息来自岩超聚能官网（yanfusion.com）及 2026-10-13 上海证券报、界面新闻的公开报道。
- YF-1 的工程参数（大半径、场强等）尚未公开，本平台的物理参数为参照 W7-X 量级的**教学模型**，不代表 YF-1 工程规格。
- 分代磁体方案按公开报道标注：YF-1 为全高温超导（全 HTS）+ 金属 3D 打印 + AI 数字孪生；YF-2 为 HTS+LTS 高低温混合超导（均采用 CICC）；公司招聘介绍中的磁体总路线表述与报道口径的差异，已在平台页脚与方案附录 C 中注明来源。
