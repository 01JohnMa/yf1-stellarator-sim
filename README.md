# YF-1 仿星器交互模拟平台

应聘岩超聚能（YAN Fusion）AI 产品经理岗位的作品：以公司在建的一代仿星器装置 **YF-1** 为对象的交互模拟平台原型，附完整产品方案。

## 文件

- **`index.html`** — 模拟平台本体（当前主页版本：等距解剖图 + 侧边栏布局的教学版），单文件网页，浏览器直接打开即可运行（无需构建、无后端）。
- **`岩超聚能仿星器交互模拟平台产品方案.docx`** — 产品方案（12 页）：事实基线、产品矩阵、YF-1 旗舰设计、分层体验、AI 全流程、游戏化体系、GEO/SEO 规划、版本路线图、指标与红线；附录含原型修正清单与面试讲述提纲。

## 当前主页版本（解剖教学版）能做什么

- **一台画出来的机器**：等距解剖图呈现十二段真空室、六组非平面超导线圈与配套柜体（52 个部件组、236 个实体），悬停可分离部件、点选查看部件说明，几何经图库自带审计校验（线端零悬空）。
- **侧边栏分层操作**：左侧栏集中深度切换与全部控件——入门（磁场 / 加热功率滑杆、预设工况、三段式诊断、三关任务）、进阶（独立密度、分解视图、磁力线与部件标注）、专家（公式实时代入数值、Q–磁场扫描图、事件日志）；右侧主区只留读数与装置图。
- **七步分步导览**：边讲边做——认识机器 → 亲手点亮 → 看懂温度 / Q / β 三个数 → 对比实验 → 亲手触发破裂再恢复 → 自己达成 Q ≥ 1 → 走进进阶与专家层；每步有高亮与完成判定，约 3 分钟走完即可独立操作教学模型。
- **同一个教学模型驱动一切**：温度、约束时间 τE、β 与增益 Q 均由同一功率平衡教学模型实时算出；β 超过 6.8% 教学上限即破裂熄灭。

> 仓库主页早期为三维产品原型（Canvas 版），现已更新为本解剖教学版；旧版保留在提交历史中。
